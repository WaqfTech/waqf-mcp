# Fihris Islamic Scholarship Web Search Skill

Enables AI agents to query verified Islamic research portals, university faculties, and fatwa archives across vetted Islamic institutions.

## Gateway Tool
- **Endpoint**: https://mcp.waqf.app/mcp?suite=search
- **Method**: tools/call
- **Tool**: waqf_search_scholarship

## Usage Example
Call waqf_search_scholarship with { "query": "شروط الزكاة في عروض التجارة", "page": 1 }.
